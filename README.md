# My Personal Portfolio 🙋🏻‍♂️

A lightweight, high-performance, single-file monochromatic portfolio website designed for a Data Science and AI Engineering professional. Built purely with semantic HTML5, modern CSS, and vanilla JavaScript—free of external dependencies, libraries, or build pipelines.

Live Demo: [mubashir2003.github.io](https://mubashir2003.github.io/My-Portfolio/)

---

## Overview

This portfolio delivers a quiet, high-contrast editorial aesthetic calibrated for recruiters and hiring managers to assess technical depth, professional experience, and production projects within ten seconds. It features accessible navigation, client-side theme switching, structured modal inspection, and responsive grid layouts.

### Key Highlights

* **Zero Dependencies**: Pure HTML5, CSS custom properties, and vanilla ES6+ JavaScript. No npm, webpack, Tailwind, or external icon packs.


* **Single-File Architecture**: Entire application logic, structural styling, responsive layout definitions, and semantic content reside inside `index.html`.
* **Double-Click Executable**: Runs straight from `index.html` locally or deploys instantly to static platforms like GitHub Pages, Vercel, or Netlify.
* **Monochromatic Grayscale System**: High-contrast dark and light themes with system-level preference detection and persistent state memory via `localStorage`.
* **Zero FOUC (Flash of Unstyled Content)**: Inline pre-render logic prevents theme flicker during initial page paint.
* **Accessible & Screen-Reader Ready**: Built using semantic landmarks, visible focus boundaries, keyboard focus trapping in dialogs, ARIA dialog specs, and `@media (prefers-reduced-motion)` compliance.

## Page Structure

The portfolio follows an intentional narrative sequence:

1. **Hero**: Professional positioning statement, portrait container, primary action buttons, and scroll cue.
2. **About Me**: Professional summary covering focus areas and core methodology.


3. **Education**: Degree details, institution credentials, graduation timeline, and metrics.


4. **Experience**: Reverse-chronological timeline detailing verified impact metrics across consultancy, governance, and analytics roles.


5. **Skills**: Categorized competencies divided into Data Science & ML, BI & Visualization, and CRM & Automation.


6. **My Projects**: Four featured project cards with configurable image banners, technology tags, external web links, and interactive modal deep-dives.
7. **Contact**: Centered, monochromatic quick-access links for LinkedIn, GitHub, Email, and Resume.
